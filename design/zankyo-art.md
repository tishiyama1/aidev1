# 残響 アートディレクション（基準ポスター準拠）

基準: 人間から渡されたポスター画像（縦長、白い鯨、赤い裂け目、縦書きの「残響」）。

ゲームシステムは変えない。変えるのは見た目と演出だけ。ゲーム内に説明は置かない。

## 1. ポスターの視覚的特徴

| 観点 | 特徴 |
| --- | --- |
| 地の色 | 青みのある黒（深海の墨色）。中心に向かってごくわずかに青緑がかる。明るい面積はほとんどない |
| 主役の色 | 骨・羊皮紙のような白（`#e9e2d0` 前後）。鯨とタイトル文字だけがこの色 |
| 副色 | 冷たい青緑〜青灰（岩の縁の光、波紋、遠くの灯） |
| 脅威の色 | 深い赤（`#c01818` 前後）。**面ではなく細い線**として、画面の上から裂け目のように走る。縁には細かい毛のような鋸歯がある |
| 質感 | 粗い粒子（フィルムグレイン）、岩の縁に白い飛沫のような点描、水中の浮遊粒子（マリンスノー） |
| 形 | 岩は垂直に割れた柱状で、鋭く角張る。波紋は**点線の同心楕円**。鯨は輪郭の柔らかい単純なシルエット |
| 構図 | 縦に深く落ちていく。中心の小さな白い光（鯨）に視線が集まり、周囲は広い闇。遠くに小さな青緑の灯 |
| 文字 | 縦書きの太い明朝体、かすれた質感。小さな添え書きは字間の広い細明朝体 |
| 空気 | 静か、重い、息を殺している。派手な発光や彩度の高い色は一切ない |

## 2. ゲームのどの要素にどう反映するか

| ゲームの要素 | いま | 反映後 |
| --- | --- | --- |
| 背景 | 単色の黒 | 青みの黒に、中心だけわずかに明るい深度グラデーション。フィルムグレイン。漂う浮遊粒子 |
| プレイヤー | 白い点 | 小さな白い鯨のシルエット（骨色）。進む向きへ体を向け、尾を揺らす。当たり判定は変えない。周囲に弱い光 |
| 探知音の波紋 | 実線の円 | 点線の同心円。本体の後ろに、遅れて弱い輪が2つ続く（残響そのもの） |
| 壁（記憶された面） | 薄い青白い短線 | 骨色〜青灰の短線。縁には白い飛沫のような点を散らす。岩の塊は青緑がかった黒の面に、粗い粒状の点描 |
| 怪物 | 塗りつぶしの赤い星 | 面を持たない、細い深紅の線だけの存在。歯を内側に向けた輪（顎）。縁に細かい毛のような鋸歯。発見されたときは輪が少し開く |
| 番人 | オレンジの円 | 深紅寄りの錆びた朱色の線画。形（円＋楕円＋瞳）は変えず、読み分けを保つ |
| 水 | 明るい青の波線 | 鋼のような青緑の細い波線 |
| 結晶 | 紫 | 冷たい青藍（薄い藤色）。共鳴の光は白に近く |
| 出口 | 緑の菱形 | 遠くの小さな青緑の光る球。周りに薄い同心円。方向を示す弧は従来どおり |
| 危険の予兆 | 赤い周辺減光 | 画面の縁から、**細い深紅の亀裂**が伸びてくる（ポスター上部の裂け目）。怪物が近いほど長く、多く、脈打つ |
| UI（階層表示） | 等幅フォントの「B1」 | 明朝体の骨色、縦書き。位置はポスターのタイトルと同じ右上 |
| タイトル | 画面中央の細字 | ポスターと同じ縦書きの太い明朝体、右上。冒頭だけ表示し、ゆっくり消える。添え書きは入れない |
| 死亡画面 | 赤い数字 | 赤い亀裂が画面全体に走る。数字は骨色、縦書きの階層は残す |
| 音 | 洞窟の反響 | 低い水中のうなり（ごく小さく常時）。探知音は少し長い下降音（鯨の声に近づける）。システム音は変えない |

### 意図的に入れないもの

- ポスターの添え書き「その声は、道にも、罠にもなる。」は、ゲーム内に入れない。ゲームの仕組みを言い当てた文なので、ゲーム内の説明禁止に触れるおそれがあるため。
- 彩度の高い発光、光る縁取り。ポスターの静けさと合わないため。

## 3. 実装方針

- 技術: 既存のcanvas描画のまま。外部画像・フォントは使わない（ポスターの画像自体は読み込まない）。
- 質感: グレインは、起動時に小さなノイズ画像を1枚だけ作って画面全体に敷く。毎フレームの再生成はしない。
- 点描の岩: 既存のハッシュ関数を使い、タイルごとに位置を固定する。再描画で点がちらつかない。
- 鯨のシルエット: 小さなベジェ曲線で描く。体の向きは進行方向へなめらかに追従させる。
- 怪物: 歯の本数と長さは、個体ごとの固定値にして、ちらつかせない。
- 亀裂: 画面の四辺ごとに、起動時にランダムな折れ線を数本つくる。危険度（既存の `G.danger`）に応じて、描く長さと不透明度を変える。
- 浮遊粒子: 数十個。ゆっくり漂い、画面の端で回り込む。
- 可読性の担保:
  - 怪物、番人、結晶、水、出口は、色相だけでなく**形**でも見分けられるままにする。
  - 壁の読みやすさ（岩の塊の濃さ、短線の明るさ）は下げない。以前のレビューで最大の問題だったため。
  - 操作に関係する当たり判定、速度、音の仕組みは変更しない。
- 検証:
  - 前後のスクリーンショットで、壁・怪物・出口が判別できるか確認する。
  - 既存の自動プレイと回帰テストを再実行し、挙動が変わっていないことを確認する。
  - スマホ（iPhone 13エミュレーション）の表示を確認する。

## 実装後の記録

- 計画との違い:
  - フィルムグレインは、当初「画面全体に合成モードで敷く」予定だったが、描画が約2倍遅くなった（ヘッドレス計測でフレーム時間が16.7msから33msに）。
  - そこで、あらかじめ作った粒の小さな画像を、通常の描画で重ねる方式に変えた。計測では元の16.7ms（p95は33ms）に戻った。
  - 死亡画面の階層の数字は、怪物の絵と重ならないよう、少し上に置いた。
  - 画面サイズは、見えている領域を直接測る方式に変えた（スマホSafariで画面が伸びる問題への対応。慣性・めぐりで先に直した方式）。
- 添え書きは、計画どおり入れていない。
- 変えていないもの: 当たり判定、移動速度、音の仕組み、怪物の挙動、階層の生成。
- 未確認: 音の聴感（ヘッドレス環境のため）、実機、Safari/Firefox。

## 追記: 鯨の視点を真上に合わせた

操作する画面は洞窟を真上から見た平面図だが、鯨はポスターの横向きのシルエットのままだった。視点が食い違っていたため、真上から見た姿に描き直した。

- 輪郭は左右対称。胸びれは左右に一対、尾びれは横に開き、中央に切れ込みがある。
- 泳ぐと、尾が上下ではなく左右に揺れる。
- 向き、大きさ、当たり判定、色は変えていない。
- 未確認: 実機、Safari/Firefox、手によるプレイ。

## 追記: 鯨のシルエットと泳ぎの見直し（実写の参考画像）

真上から撮ったナガスクジラ類の写真を参考に、さらに描き直した。前回の版は、短くて丸い魚のように見えていた。

- 形: 細長い体（長さは幅の約6〜7倍）、丸みのある吻、肩のあたりが最も太く、尾に向かって細くなる。胸びれは細く後ろへ流れる。尾びれは小さく、中央に切れ込み。
- 泳ぎ: 背骨にあたる線が、鯨が通ってきた軌跡をたどる。曲がるときは体全体が弧を描き、急な角にならないよう滑らかにしている。泳ぐと、頭から尾へ向かって波が走り、尾に近いほど大きく揺れる。速いほど振れ幅が大きい。
- 全長は1.7マス（描画のみ）。当たり判定、速度、色は変えていない。
- 未確認: 実機、Safari/Firefox、手によるプレイ、長時間の描画への影響。

## 追記: 海中前提での足音と川の見直し

洞窟（陸）の前提が残っていた2点を、海中の意味づけに改めた。形と挙動は変えていない（音が出る・近づくと怪物に届く・通ると大きな音がする、はそのまま）。

- 足音: 水を切る尾の動きの音（低くやわらかい水の「ざっ」）にした。以前は硬い足音だった。
- 川（水たまり）: 熱水噴出孔のような泡の柱にした。音が通ると、床から立ちのぼる泡が、上がるほど大きくなって消える。通ると大きな音が出る（泡のごぼごぼ）。以前は波線と水しぶきの音だった。
- 光結晶、目の形、怪物は変えていない。
- 未確認: 音の聴感、実機、Safari/Firefox。
