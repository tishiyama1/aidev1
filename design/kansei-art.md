# 慣性 アートディレクション（基準ポスター準拠）

基準: 人間から渡されたポスター画像（縦長。鏡の間の舞踏会場、白磁の機械仕掛けの踊り子、割れる鏡、倒れる黒衣の人形、縦書きの「慣性」）。

ゲームシステムは変えない。変えるのは見た目と演出だけ。ゲーム内に説明は置かない。

## 1. ポスターの視覚的特徴

| 観点 | 特徴 |
| --- | --- |
| 舞台 | バロックの大広間。深紅のビロードの幕、金の装飾の柱とアーチ、蝋燭の灯り、磨かれた寄木の床（菱形の模様、艶のある反射） |
| 色 | 深い赤（臙脂）、古金（アンティークゴールド）、象牙・白磁の白、床と衣装の黒に近い茶。割れた鏡のガラスにだけ冷たい青緑 |
| 主役 | 白磁の機械仕掛けの踊り子。関節や胸に金の歯車と機構がむき出し。肌の磁器には金継ぎのような金色の割れ線 |
| 動き | 大きく伸びた体と、背後に連なる薄い残像（同じ踊り子が間隔を置いて重なる）。弧を描く光の軌跡。赤い糸が長くたなびく |
| 衝突 | 右の大鏡が踊り子の手で砕ける。ガラスの破片、歯車、磁器のかけらが飛び散る |
| 敵 | 黒い衣と白い仮面を着けた、同じ機械人形たち。倒れ、砕け、歯車がこぼれる |
| 質感 | 磁器のひび、紙のように裂けたスカート、床の映り込み、細かい粒状感。装飾は繊細で多い |
| 文字 | 縦書きの太い明朝体。象牙色で、かすれと金の傷が入る |
| 空気 | 優雅で、同時に壊れている。美しい舞と、止まれないことの代償 |

## 2. 現在のゲームシステムとの相性

| ゲームの要素 | 相性 |
| --- | --- |
| 惰性で動き、止まれない | 非常に良い。ポスターの主題そのもの（残像と軌跡で「止まれない身体」が描ける） |
| 反射するバンパー、反射する外周の枠 | 非常に良い。割れる鏡として描ける（ぶつかると鏡面に亀裂が走り、破片が飛ぶ） |
| 通り道の敵をまとめて倒す | 良い。人形たちが砕け、歯車がこぼれる絵になる |
| 敵の攻撃予告のマス | 注意が要る。ポスターの色の大半は赤と金なので、背景まで赤くすると予告が読めなくなる。盤面は暗く、幕の赤は盤面の外に限る |
| 盤面が格子 | 良い。寄木の床の菱形、金の継ぎ目として自然に見える |
| 4種類の敵を形で見分ける | 維持する。仮面・歯車・細剣・鐘という別々の形を、同じ「人形」の素材（黒、象牙、金）で描き分ける |
| ターン制で静止して読む | 良い。ポスターは静止画なので、止まった画面の美しさがそのまま効く |

## 3. 反映方針

| 要素 | 反映 |
| --- | --- |
| 背景 | 盤面の外は、深紅の幕（縦のひだ、上部に金の房飾り付きの垂れ幕）。蝋燭の灯りがゆっくり揺れる。金色の埃が漂う。周辺は暗く落とす |
| 盤面 | 暗い寄木の床。升目の継ぎ目を金の細線にする。斜めに薄い艶の光。外周は金の額縁（四隅に装飾） |
| 壁 | 象牙色の大理石の台座。上面にハイライト、縁に金の細線 |
| バンパー | 金枠の鏡。斜めの映り込み。ぶつかると亀裂が走り、ガラスの破片が散る |
| 外周の反射枠 | 鏡の額縁。冷たい青緑のガラスの縁が、金の枠の内側で脈打つ |
| プレイヤー | 白磁の踊り子（上から見た円盤）。金の歯車の輪と、金継ぎ状のひび。進んだ道筋に薄い残像が連なり、赤い糸が後ろへたなびく（速いほど長い） |
| 敵 | 黒・象牙・金の人形。トゲ＝金歯車の円盤、殻＝白磁の仮面（装甲の数＝金の点）、槍兵＝金の細剣、迫撃＝青銅の鐘。形は今のまま、素材感だけを変える |
| 攻撃予告 | 形は変えない（角の印、射線、照準）。色は鮮やかな朱、金橙、蘭色で、暗い床の上で読める強さを保つ |
| 撃破 | 人形が砕ける。磁器と金のかけらが三角形で飛び散り、歯車が一つこぼれる |
| 効果 | 得点は金の明朝体。連続撃破の倍率は金の斜体。被弾は幕の赤の閃光 |
| UI | 得点・BESTは金と象牙の明朝体。体力は金の輪のある深紅の宝石。階層は「第三幕」のように漢数字で |
| 階層の切り替え | 幕が左右に開く。開く前に「第三幕」と出る |
| タイトル | 縦書きの太い明朝体「慣性」を左上に、象牙色に粒状のかすれと金の傷を入れて、冒頭だけ表示 |
| ゲームオーバー | 幕が左右から閉まる。閉まった幕の上に、得点を金で表示 |
| 音 | 撃破は、オルゴールのような澄んだ音を重ねる。鏡にぶつかる音は、ガラスのような高い音に |

### 意図的に入れないもの

- ポスターの添え書き「止まれない身体で、運命を曲げる。」は、ゲームの仕組みを言い当てた文なので、ゲーム内の説明禁止に触れるおそれがあり、入れない。
- 具象的な人物の細密な描写（顔、手足）。ゲームは真上から見た盤面で、操作と読み取りが最優先のため、人形は記号的な形に再解釈する。
- 背景に建築物（柱やアーチ）を細かく描くこと。盤面の周りの情報量が増え、攻撃予告が読みにくくなるため。幕・灯り・額縁で場の空気を作る。

## 4. 実装方針

- 技術: 既存のcanvas描画のまま。外部画像・フォントは使わない。
- 幕の背景は、画面サイズが変わったときに一度だけ別のcanvasに描いておき、毎フレームは画像として貼る。
- 装飾は線と単純な図形（円弧、三角形、菱形）で描く。
- 可読性の担保:
  - 盤面（床・壁・バンパー）は、以前より少しだけ暖かくするが、明暗の関係は変えない（床は暗く、壁は明るい）。
  - 攻撃予告の色は、暗い床の上で今と同じかそれ以上のコントラストを保つ。
  - 移動先の印、経路の予告、跳ね返りの矢印は、色だけ変える。形と位置は変えない。
- 検証:
  - 前後のスクリーンショットで、敵4種・壁・バンパー・攻撃予告・移動先の印が判別できるか確認する。
  - 既存の自動プレイと、スマホ（iPhone 13エミュレーション）のタップ検査を再実行し、挙動が変わっていないことを確認する。
  - 描画時間を前後で比較する。

## 実装後の記録

- 計画との違い:
  - 攻撃予告のマスの塗りを、少し濃くした（暗い床の上でも、以前と同じ強さで読めるようにするため）。
  - 得点などの数字の背後に、暗い板を敷いた。幕の上部の金の縁取りが数字を横切って見づらかったため。
  - 敵の「槍兵」は、形（三角形）を変えずに、金の細剣として描いた。「迫撃」は青銅の鐘の入った四角い箱にした。
- 添え書きは、計画どおり入れていない。
- 変えていないもの: 移動規則、敵の挙動、当たり判定、攻撃予告のマスの位置、移動先の印の位置と形、スコア、階層の生成。
- 描画時間: 負荷のかかる階層（F6、敵が多い状態）で、前後ともフレーム時間の中央値16.7ms、p95は16.7〜16.8ms。
- 未確認: 音の聴感（ヘッドレス環境のため）、実機、Safari/Firefox。
