# 慣性 見せ方の刷新（戦闘機の空中戦ジオラマ）

基準: 人間から渡された構成図（「操作と飛行演出の視点切替」）。

- ① 真上から操作 → ② 斜め視点で飛行 → ③ 真上に戻る の3コマ。
- 添え書き: 「同じ盤面・同じ移動を、カメラだけ切り替えて見せる。」

ゲームシステムは変えない。変えるのは見せ方と演出だけ。ゲーム内に説明は置かない。

先行する #6（バロックの舞踏会場）は、方向が変わるため、この作業では使わない。この作業は `main` から始める。

## 1. 構成図の分析

| コマ | 内容 |
| --- | --- |
| ① 真上から操作 | 青い海の盤面を真上から見る。升目は薄い線。岩の島が数か所（緑の苔のある台形の崖）。島の周りに砂色の浅瀬。白い戦闘機が中央にいて、周囲の8マスに水色の輪（移動先の候補）。決めた経路は黄色い半透明のマスで示す。画面下に赤い戦闘機が2機、その先の地上に赤い星形の着弾マーカー |
| ② 斜め視点で飛行 | 同じ盤面を斜め上から見る。盤面は厚みのある板（ジオラマの台座）で、側面は濃い青。島は立体の岩ブロックで、上面に苔。白い機が尾を引いて飛び、真下に黄色い点線と黄色い着地マーカー。赤い機にも真下への赤い点線と、星形の着弾マーカー。背景は青空と雲 |
| ③ 真上に戻る | 白い機が新しい位置に移っている。周囲に水色の輪、機のまわりに照準の枠。通った道筋に薄い黄色のマスが残る。赤い機の予告は残ったまま |
| 空気 | 明るく、見晴らしがよい。昼の海と空。色数は少なく、操作用の色（水色・黄・赤）が風景の青・緑・茶の上ではっきり読める |

### 色

- 海: 青（`#2b6ea3` 前後）と、升目の明るい青の線。
- 空・雲: 淡い水色と白。
- 島: 岩は灰茶、上面は苔の緑、周りの浅瀬は砂色。
- 自機: 白（青い差し色）。
- 敵機: 赤（濃い赤、紺の差し色）。
- 操作の色: 水色（移動先）、黄（経路・着地）、赤の星形（着弾）。

## 2. 現在のゲームシステムとの相性

| ゲームの要素 | 相性 |
| --- | --- |
| 操作フェーズ（移動先を選ぶ）と行動フェーズ（結果が動く） | 非常に良い。もともと2段階（選ぶ → 動く）なので、カメラの切り替えがそのまま対応する |
| 盤面は格子で、マスの位置が重要 | 操作は真上から行うので、読み取りと操作の精度は今のまま保てる |
| 経路上の敵をまとめて倒す | 空中戦として描ける。自機が通過した敵機が撃墜される |
| 敵の攻撃予告（マスに印が出る） | 地上の着弾マーカーとして描ける。敵機が攻撃予告のマスへ向かって攻撃する絵になる |
| 壁（通れない） | 岩の島 |
| 跳ね返るバンパー、反射する外周 | 気流の渦（バンパー）、盤面の縁の気流の壁（外周）。機が弾かれる |
| 敵4種（トゲ、殻、槍兵、迫撃） | 機体の形で見分ける。機動隊（トゲ）、重武装機（殻）、迎撃機（槍兵）、爆撃機（迫撃） |
| ターン制で静止して読む | 操作中は真上で静止した盤面なので、今まで通り |
| 1手ごとの長さ | 注意が要る。斜め視点の演出の分だけ、1手が長くなる。往復のカメラ移動を短く（約0.3秒ずつ）し、全体で今より0.3秒程度の増加に抑える |

| 盤面 | 厚みのある台座の上に、海のマスと島のブロック。立体の厚みは、斜めのときに側面が見える。真上のときも、影と縁の暗い帯で高さを感じさせる |

| 背景 | 空と雲。ゆっくり流れる |
| 音 | 飛行の風切り音、爆発音（低い破裂音）を加える。撃破の音階はそのまま |

### 実装の考え方

- 描画は2Dのcanvasのまま、軸測投影（遠近なしの斜め投影）で立体に見せる。
  - 盤面の平面は、1つのアフィン変換（回転と圧縮）で描けるので、既存の予告・経路・印の描画をそのまま使える。
  - 高さのあるもの（島、機体、爆発）は、高さを画面の縦方向のずれとして加える。
- カメラの角度は、真上（90度）から斜め（約40度、わずかに回転）まで補間する。真上のときは、今までと座標が完全に一致する（タップ位置が変わらない）。
- 描き順は、奥から手前へ並べて重ねる。
- 機体は、ゲーム内の座標と向きから、多角形で描く。外部の画像は使わない。

### 守るもの

- 当たり判定、移動規則、敵の挙動、攻撃予告のマスの位置、移動先の印の位置と形、スコア、階層の生成。
- 操作フェーズの読み取り（移動先、経路、予告）。
- ゲーム内に説明を置かない。

### 検証

- 真上のときのタップ位置が、変更前と一致する（スマホの表示条件を変えても）。
- 前後のスクリーンショットで、操作フェーズの印が読めること。行動フェーズで、機・撃墜・着弾が読めること。
- 既存の自動プレイと回帰テスト。描画時間の前後比較。

## 実装後の記録

- 実装:
  - カメラは、真上（90度）から斜め（約42度、約15度の回転）まで約0.3秒で補間する。操作中は真上で、座標は変更前と完全に一致する。
  - 盤面の平面は、1つのアフィン変換で描く。高さのあるものは、点ごとに投影して描く。
  - 海・浅瀬・格子・島の影は、階層ごとに1枚の画像にまとめておく。
- 計画との違い:
  - 1手の長さは、カメラの傾き分（0.28秒）だけ延びた。戻りの0.3秒は、既存の敵の動きの時間と重ねたので、延びていない。
  - 「効果」の項目で、敵機の名称（機動隊、重武装機、迎撃機、爆撃機）は、ゲーム内には出さず、形と色だけで描き分けた。
- 描画時間: 最初の実装では、斜め視点の間のフレーム時間が約2倍（33ms）になった（ヘッドレス計測）。次の2点で、変更前と同じ（中央値16.7ms）に戻した。
  - 海を1枚の画像にして貼る。
  - 傾いている間は、その画像の補間を切る（海は単色のため、見た目の差は小さい）。
- 添え書きと説明は、入れていない。
- 未確認: 音の聴感（飛行の風切り音、爆発音）、実機、Safari/Firefox。

## 追加改修（立方体のジオラマ・速度・機動）

人間からの追加指示: 空を高くして立方体の中の戦闘に見せる／行動パートの速度を3段階に／機銃・墜落・インメルマンターンなど戦闘機らしい動作を足して派手に。

- 立方体: 盤面の上に高さ約3.4マスの透明なガラスの箱。縁は細い白線、奥の面に空と雲、箱の中に雲が浮く。台座は水の断面と石の柱。
- 速度: 画面下の3つの丸ボタン（またはキー1・2・3）で、ゆっくり／ふつう／はやい。倍率は2.5・1.7・1.0。選択は保存される。ゲームの規則と判定は速度に依存しない。
- 撃破: 自機が敵機に機銃を撃ち込み（曳光弾と発砲の閃光）、敵機は煙と火を引いて回転しながら墜落し、海面で爆発する。
- 機動: 方向が大きく変わる経路と、衝突・停止で終わる経路で、自機がインメルマンターン（半宙返り＋半ロール）で向きを反転する。それ以外の曲がりではバンクする。
- 音: 機銃、墜落の笛、上昇音を追加（聴感は未確認）。
- 検証: 操作フェーズのタップ位置は変更前と一致（4条件）。自動プレイ20回で打ち切り0、規則は不変。描画時間の中央値は飛行中も16.7ms（ヘッドレス計測、p90は33ms）。連続コマの画像で、立方体・曳光弾・爆発・インメルマンターンの姿勢を確認。
- 未確認: 音の聴感、実機のフレームレート、Safari/Firefox、人間の手による通しのプレイ。

## 追加改修その2（品質・カメラ・立方体）

人間からの指示: 海と島の絵の品質が低い／立方体は各辺を同じ長さに／空間の雲は視認性が落ちるので不要／行動パートはカメラを寄せる。

- 立方体: 高さを盤面の幅と同じ（11マス）にした。飛行高度は少し上げた。空間の雲はすべて外した（空はグラデーションのみ）。
- カメラ: 行動パートでは約1.75倍まで寄り、自機を追う。自機の移動が終わった後は、敵の動きが見えるよう約1.4倍に戻して盤面の中央寄りへ。操作フェーズは今までどおり真上・等倍で、タップ位置は変わらない。
- 海: 陸からの距離で色を変える（砂 → 浅瀬の青緑 → 外海の濃い青）。波の白い縁、広い範囲の色むら、光の帯と光の粒、島の柔らかい影。
- 島: 隣り合う島は高低差のある地形としてつながる（隣より低い側面だけ描く）。崖は上が明るく下が暗いグラデーションで、地層の線とひび、縁にあふれる苔、水際の白い波。上面はグラデーションと斑点、松の木は三段で影つき、低い所には岩。
- 未確認: 音、実機のフレームレート、Safari/Firefox。ヘッドレスの描画時間は、この改修前の版でも中央値33msだった（先の16.7msは計測時の環境差と思われる）ので、実機での確認が必要。画像は参照画像を直接見られていない部分があり、文面の指示から解釈した。

## 追加改修その4（写実的な表現）

人間からの指示: 壁面に雲を描いてよい（視認性の考慮は不要）。重さは気にせず、全体を写実的に。

- 新しいファイル `kansei/art.js`: 外部の画像を使わず、起動時に手続きでテクスチャを生成する。
- 壁面: 雲の浮かぶ空の写真のようなテクスチャ（複数階層のノイズで雲をつくり、光の向きで陰影）を、立方体の奥の壁に貼る。
- 海: ピクセルごとに計算。水深に応じた色、うねりの法線による陰影、太陽の反射のきらめき、浅瀬の水底の光の網（コースティクス）、砂浜（湿った砂と乾いた砂、粒）、波打ち際の泡。
- 島: 玄武岩の柱のテクスチャ（柱ごとの色むら、層の割れ目、鉄さび、地衣類）を、光の向きに合わせて面ごとに陰影をつけて貼る。上面は苔と草のテクスチャ。松は枝ぶりのあるスプライト。
- 台座の断面: 水中の光の筋と気泡、積み上げた石ブロック（不揃いな高さ）のテクスチャ。ガラス越しの反射。
- 機体: 面の向きで明るさを変え、胴体にハイライト、キャノピーに反射、エンジンの光は加算合成。
- 煙・炎・飛行機雲: ノイズでふちを崩した柔らかいスプライト。四隅を暗くする周辺減光。
- 未確認: 実機の描画速度（生成と描画は重くなっている。海は階層ごとに同期生成）、音、Safari/Firefox。
